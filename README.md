# CatGamerRock — Front-end

Proyecto formativo SENA para la evidencia **GA7-220501096-AA4-EV03**.

## Requisitos
- Node.js instalado.
- npm (se instala junto con Node.js).

## Cómo ejecutar
1. Descomprime la carpeta.
2. Abre una terminal dentro de esta carpeta.
3. Ejecuta `npm install`.
4. Ejecuta `npm run dev`.
5. Abre en el navegador la dirección local que muestra Vite.

## Cómo generar la versión de producción
Ejecuta `npm run build`. Los archivos finales se generan en `dist/`.

## Tecnologías
- React y JSX para construir componentes.
- Vite para ejecutar y compilar el proyecto.
- CSS para los estilos.
- Lucide React para iconos.

## Funcionalidades implementadas
- Navegación entre Inicio, Catálogo, Favoritos e Iniciar sesión.
- Búsqueda de videojuegos por nombre.
- Filtro por categoría.
- Tarjetas de videojuegos con precio y acción para ver detalle.
- Vista de detalle del videojuego seleccionado.
- Botón de favoritos con estado en la interfaz.
- Formulario de inicio de sesión demostrativo.

> Nota: es un prototipo front-end académico. El inicio de sesión no valida usuarios reales ni procesa pagos.
